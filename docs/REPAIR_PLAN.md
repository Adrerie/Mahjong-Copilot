- 每个拒绝添加的分支给反馈，吃牌三张逐项校验。键盘打开时保留分析入口，增大副露切换区，翻译 Done/Pong/Gang。

## 2. 再修川麻计番（S01、S03–S06）

文件：`utils/sichuanAnalyzer.ts`、`constants.ts`，仅在规则需要时补 `types.ts` 和输入字段。

- 先选择有明确来源的一套参考规则，统一指数番数与结算倍数；不能把清对“8倍”载入成8番，也不能根据城市名统一认定16倍。
- `33344466699977s` 是清一色大对子，无根，含9。若采用清一色2番＋大对子1番，仅此为3番/8倍；16倍或满牌需额外规则证据。用户当前未确定牌桌口径。
- 修复明碰重复计为刻子、全带幺九只看1/9、三根七对遗漏；基于合法拆分判断，不只是修改常量。
- 先支持一套明确参考规则；门清、自摸、封顶只添加已证实的少量选项。重庆预设等待来源，不设计通用规则语言。

验收牌例：清大对上述牌例；碰111筒和999筒＋`123456m77p`不能报对对胡；`12378911m123789p`核对带幺九；`11114444777799s`核对七对和三根。明确每项番数、倍率、规则来源与叠加条件。
