## 尚存限制（未建模，一律不计番）

- 花牌：牌模型只有 34 种牌面，不含春夏秋冬梅兰竹菊。
- 无番和：1 番，需「除门前清/自摸外无其他番种」的全局判定，未接入。
- 杠上开花/抢杠和只按「杠后和牌 + 和牌方式」两个已记录事实判定，不追踪杠的具体轮次。
- Android 仅做构建与 390×844 视口检查，未在真机或模拟器实测；仅生成 Debug APK，不发布签名包。
- 提议层仍是启发式：给缺张与番型，不给真实摸牌概率或胜率。

## 验收方式（只做一次）

- 完工统一执行 `npm test && npm run typecheck && npm run build`，推送后核对一次 Actions 的 Web 与 Android Debug APK 结果。
- 离线/真机验收需要实际设备或可用模拟器，不用 CI 通过冒充实测。
