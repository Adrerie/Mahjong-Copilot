**通过的牌例**（37 项守卫 / 14 项 P3 快照）
- `33344466699977s`：清一色2 + 对对胡1 = 3 指数番 → **8 倍**，无根（不再是 6 番/64 倍）；同一牌型带一个杠根时 3+1=4 → 16 倍。
- 碰111p + 碰999p + 暗手 `123456m77p`：基本和 0 → 1 倍（明碰不再计成暗刻）；对照真对对胡 1 → 2 倍；副露已占的牌不能再出现在暗手。
- `12378911m123789p`：带幺九 2 → 4 倍；把将牌换成 `55m` 即退回基本和；`234/567` 顺子不含幺九时不计。
- `11114444777799s`：清一色2 + 七对2 + 根×3 = 7 → 封顶 4 → **16 倍**；无根清七对 4 → 16 倍；四张同牌但整体不是七对时根仍单算。
- `11112377889999s`：清一色2 + 带幺九2 + 根×2 = 6 → 封顶 4 → 16 倍，且指数番恒等于「番型之和 + 根」，不含自摸/杠/海底。
- `11112233778899s`：可拆七对或 123/123/789/789 顺子带幺九 → 分别评分择高，清一色2 + 七对2 + 根1 = 5。
- `11119999m111199p`：七个对子都是幺九 → 七对2 + 带幺九2 + 根×3 = 7。
- 未成牌：只输出 `N 指数番 · 潜力`，概率为 0；定缺仍在 → 花猪/无法和牌；未选定缺 → 输入无效，不输出番型。

**跨拆分重复计番（本轮修复）**：对对胡与带幺九都按「合法面子拆分」判断，但同一手牌可能有两种拆分（如 `111222333m99911p` 可拆 111/222/333/999 → 对对胡 1，也可拆 123/123/123/999 → 带幺九 2）。原实现分别做存在性判断后相加，得到 1+2=3 指数番 = 8 倍。现改为**枚举暗手每个合法「4 副面子 + 1 将」拆分、各拆分成套计番后择高**，该牌例只计带幺九 2 指数番 = 4 倍；未被采用的拆分之一行标注「不叠加，口径待核」。清一色与根不依赖拆分，仍正常相加。同时校验的边界：四副幺九刻子但将牌 `55m` 非幺九 → 只有对对胡 1（2 倍）；`111222333m99977p` 顺子拆分无番、取刻子拆分对对胡 1（2 倍）；金钩钓四副明碰 + 非幺九单钓将 → 金钩钓 2（4 倍）不双计对对胡；七对与对对胡互斥（互为反例）。

**本次精简**：删除旧四川番表/倍数表/杠收益/赔付常量、`calculateSichuanMultiplier`、`getPatternName`、四川路径的 95%/90% 伪概率、四条 P2 旧缺陷快照、临时探针脚本、已执行步骤，以及本轮被替换掉的 `indexValue / ShapeRequirement / formGroups / concealedFits`（存在性检查改为拆分枚举，不留两套实现）。
