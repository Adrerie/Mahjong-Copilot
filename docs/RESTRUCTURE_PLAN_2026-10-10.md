## 剩余问题（一次集中修，勿过度设计）

1. **四川完整结算**：Hi8 下另有暗/直/补杠的即时支付、抢杠无效杠费、杠上炮转移、自摸多家付款、流局查叫/花猪和玩家先后和牌状态。当前没有四人牌局及动作历史，**不要凭单人录牌猜出这些分数**。未来确需结算时增加极少量必要事件/参与玩家字段，而非全面重建房间系统。
2. **四川地区变体**：“自摸加底／自摸加番”、封顶/底分以及杠开包赔由房间设定决定；目前只支持固定 Hi8 参考倍率。只有确定实际牌桌规则后才做可选规则集，不能混合计数。
3. **国标准确性**：待牌仍是结构听牌（未逐张核实8番资格）；81番与不计/附加组合未穷举；仍有启发式建议候选需查。端侧策略模型可以作为独立实验，不干预当前规则计番。
4. **运行检查**：验证四川事件选择、切换来源、撤销/本地恢复，以及 Android 横屏和断网下的结果；现有 GitHub Actions 只证实代码与 Debug APK 能构建。
