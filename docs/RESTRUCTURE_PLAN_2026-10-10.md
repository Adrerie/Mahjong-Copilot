## 本轮已完成（2026-10-12）

1. **国标和牌上下文**：录牌 UI 增加“未知/自摸/点和”三态选择（沿用深蓝/荧光绿/玫红样式），选中的 `GameState.winSource` 随局面一起保存与恢复；畸形值整局丢弃，不猜成自摸或点和。`不求人 / 门前清 / 自摸` 只在记录来源后计入，且不计不求人的特殊型（七星不靠/全不靠/七对/九莲宝灯）不会因此多出 4 番。
2. **全带幺假阳性已修**：改为在**同一合法拆分**内要求每副面子与将牌都含幺九或字牌，并区分明刻/暗刻。原先 `123m234p345s678s99s` 被误判全带幺；修正后该牌例实际是 平和2 + 连六1 + 三色三步高6 = 9 番（本身确为合法起和），错误在于番种来源而非是否达线。
3. **同一拆分内计番**：平和（四顺子 + 序数将）、清龙（同花色 123/456/789）、碰碰和、双/三/四暗刻、幺九刻、三风刻、四归一（需 4 张拆到 ≥2 副面子且不是杠）、七对（四张按两对、不再计四归一）全部改为按识别出的拆分计算，不再用整手牌的牌张计数推断。
4. **返工的错误识别**：明碰不再当暗刻；杠的明暗未知时不推断 明杠/暗杠/双明杠/双暗杠，也不把杠当四归一；三风刻不再认可“第三种风作将”；连六覆盖 123456/234567/345678/456789 全部四种；补上 大三元、三色三同顺、三色三步高、喜相逢、老少副、一般高、双同刻、全求人、连七对、九莲宝灯等番种。
5. **不计规则的优先级**：被高番种排除的番种不能被低番种的“另计”加回（如 大三元 不计 箭刻，混一色 不能把它加回来）；`555666777z12355m` = 大三元88 + 混一色6 + 三暗刻16 + 幺九刻3 = 113 番。
6. **建议层去误导**：缺牌按实体牌张数计算（`123456789m` 的一色三步高缺 4 张，不再报“缺 0 张”）；五门齐向听改用与主分析同一套 `calculateShanten`；末张提示只在“牌墙剩 1 张 + 13 张等效听牌形态”出现，14 张未听牌不再提示，也不再有“海底机会”一类臆测；`analyzeMCR` 的 `probability` 一律为 0（不推断摸牌胜率）。
7. **`calculateMCRExtras` 截断已修**：末张事件番的加番计算改为扣除副露牌张，不再 `slice(0, 14)` 截断实体牌。
8. **测试精简**：`tests/regression.ts` 由 51 项守卫 + 12 项错误输出快照压缩为 **30 项守卫、0 项快照**；保留输入边界、四川不回退、国标结构/起和/来源/特殊结构/拆分计番/建议层的关键正反例。不再新增“错误行为必须保持错误”的快照。

## 仍存在（保守未建模，报告里必须说明）

- **无字段的上下文**：和牌张本身（边张/坎张/单钓将）、末张与绝张事件（海底捞月/妙手回春/杠上开花/抢杠和/和绝张）、杠的明暗与补杠、门风刻/圈风刻、花牌、无番和。这些一律不计番，`missingContext` 只报告缺什么。
- **组合龙牌例只计结构番**：组合龙按九个指定牌位识别，不再把它当三副面子去叠加面子类番种，因此这类牌可能少计四归一/连六等；属于保守少算，不会虚报。
- **不计规则表仍有不确定处**：全不靠/组合龙/五门齐的 `includes`/`excludes` 冲突已按“高番排除优先、低番不能加回”统一处理，个别番种组合与正式表可能有差异。
- **番种覆盖未达 81 番**：缺的花色/字牌细节番（如 组合龙之外的特殊型、部分事件番）尚未补，因此结论始终区分 `met` / `unverified` / `unmet`，不把局部求和说成完整结算。
- **建议层仍是启发式**：只报缺牌与向听，不保证最优，也不提供收益或胜率。
- **验收范围**：Web 构建与 GitHub Actions（Web + Android Debug APK）通过；Android 真机与完全离线场景仍未验收。
